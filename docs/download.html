Cómo instalar

  1. Descarga la versión que quieras en uno de los botones de abajo.
  2. Si viene en un .zip, descomprímelo. Después abre UE4ModLauncher.exe: no necesita instalación.
  3. Crea un perfil e indica el .exe y la carpeta Paks del juego. Si no sabes dónde están, mira la guía de ayuda.

Si el antivirus bloquea la descarga o el programa, casi siempre es un falso positivo. Cómo solucionarlo está en la sección del antivirus; hazlo solo con archivos descargados desde esta página o desde el repositorio oficial.

How to install

  1. Download the version you want with one of the buttons below.
  2. If it comes in a .zip, unpack it. Then open UE4ModLauncher.exe: it needs no installation.
  3. Create a profile and point it at the game's .exe and Paks folder. If you don't know where they are, see the help guide.

If your antivirus blocks the download or the program, it is almost always a false positive. The fix is in the antivirus section; only do it with files downloaded from this page or the official repository.
