Hecho para tener varios juegos modeados a la vezBuilt for juggling more than one modded game

Cada juego tiene sus propias reglas. El launcher las recuerda por ti.Every game has its own rules. The launcher remembers them for you.

Perfiles por juegoOne profile per game

Cada perfil guarda su .exe, su carpeta Paks y su propia colección de mods. Cambiar de juego es elegir un desplegable.Each profile keeps its own .exe, Paks folder and mod collection. Switching games is just picking a dropdown.

Despliegue automáticoAutomatic deployment

Al pulsar Jugar, los mods pasan a la carpeta del juego; al cerrarlo, vuelven a tu perfil. Sin arrastrar archivos.Hit Play and your mods move into the game's folder; close it and they move back. No dragging files by hand.

A prueba de cierresCrash-safe

Si el launcher se cierra de golpe con mods desplegados, los recupera automáticamente la próxima vez que lo abras.If the launcher is killed while mods are deployed, it recovers them automatically the next time you open it.

Mods sin salir de la appManage mods without leaving the app

Añade archivos .pak directamente o abre la carpeta del perfil con un clic.Add .pak files directly, or open the profile's folder with one click.

Universal UE4 Unlocker opcionalOptional Universal UE4 Unlocker

Activa la consola de comandos de UE4 por perfil, solo cuando el juego la soporte. Ten en cuenta, que no esta incluido, tienes descargartelo tu y elegir la ruta del dll del Universal UE4 Unlocker, para más información mira la guia de ayudaEnable UE4's command console per profile, only where the game supports it. Please note that it is not included; you need to download it yourself and select the path to the Universal UE4 Unlocker DLL. For more information, check the help guide.
