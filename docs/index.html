El .exe del juego

Es el archivo que se elige en el campo del ejecutable del perfil. Prueba el método que corresponda a dónde tienes el juego.

Steam

  1. Abre tu Biblioteca y haz clic derecho en el juego.
  2. Elige Administrar → Explorar archivos locales.

Epic Games

  1. En la Biblioteca, pulsa los tres puntos (⋯) junto al juego.
  2. Elige Administrar y pulsa el icono de carpeta junto a Instalación.

Otra tienda o con acceso directo

Haz clic derecho en el acceso directo del escritorio y elige Abrir la ubicación del archivo.

Con el juego abierto

  1. Pulsa Ctrl + Mayús + Esc para abrir el Administrador de tareas.
  2. Ve a la pestaña Detalles, haz clic derecho en el proceso del juego y elige Abrir la ubicación del archivo.

En muchos juegos UE4 hay un .exe en la carpeta principal y el ejecutable real en NombreJuego\Binaries\Win64\NombreJuego-Win64-Shipping.exe. Elige el que arranca el juego; si con uno no funciona, prueba con el otro.

The game .exe

This is the file you pick in the profile's executable field. Use the method that matches where the game is installed.

Steam

  1. Open your Library and right-click the game.
  2. Choose Manage → Browse local files.

Epic Games

  1. In the Library, click the three dots (⋯) next to the game.
  2. Choose Manage and click the folder icon next to Installation.

Another store, or a desktop shortcut

Right-click the desktop shortcut and choose Open file location.

With the game running

  1. Press Ctrl + Shift + Esc to open Task Manager.
  2. Go to the Details tab, right-click the game's process and choose Open file location.

Many UE4 games have an .exe in the main folder and the real executable at GameName\Binaries\Win64\GameName-Win64-Shipping.exe. Pick the one that starts the game; if one doesn't work, try the other.

La carpeta Paks

Está dentro de la carpeta del juego y contiene los archivos .pak del propio juego. El launcher se encarga de crear y usar la carpeta ~mods por ti.

La ruta suele tener esta forma:

NombreJuego\Content\Paks

Desde la carpeta del .exe

  • Si el .exe está en la carpeta principal, entra en NombreJuego → Content → Paks.
  • Si estás en Binaries\Win64, sube dos carpetas hasta NombreJuego y entra en Content → Paks.

Si no la encuentras

  1. Abre la carpeta principal del juego en el Explorador.
  2. Escribe *.pak en el buscador de arriba a la derecha y espera.
  3. Clic derecho en cualquier resultado → Abrir la ubicación del archivo. Esa es la carpeta Paks.

Para copiar la ruta: haz clic en la barra de direcciones del Explorador, pulsa Ctrl + C y pégala en el launcher.

The Paks folder

It lives inside the game's folder and holds the game's own .pak files. The launcher creates and uses the ~mods folder for you.

The path usually looks like this:

GameName\Content\Paks

From the .exe folder

  • If the .exe is in the main folder, open GameName → Content → Paks.
  • If you are in Binaries\Win64, go up two folders to GameName and open Content → Paks.

If you can't find it

  1. Open the game's main folder in File Explorer.
  2. Type *.pak in the search box at the top right and wait.
  3. Right-click any result → Open file location. That is the Paks folder.

To copy the path: click File Explorer's address bar, press Ctrl + C and paste it into the launcher.

Perfiles y mods

El launcher guarda tus perfiles, y los mods de cada uno, en tu carpeta de usuario, no junto al .exe.

  1. Pulsa Win + R.
  2. Pega %LOCALAPPDATA%\UE4ModLauncher y pulsa Intro.
  3. Dentro, la carpeta Profiles tiene una subcarpeta por juego.

Para abrir directamente la carpeta de mods de un perfil, usa el botón de abrir carpeta dentro del launcher.

Profiles and mods

The launcher keeps your profiles, and each one's mods, in your user folder, not next to the .exe.

  1. Press Win + R.
  2. Paste %LOCALAPPDATA%\UE4ModLauncher and press Enter.
  3. Inside, the Profiles folder has one subfolder per game.

To open a profile's mods folder directly, use the open-folder button inside the launcher.

Universal UE4 Unlocker (UUU)

Si el perfil necesita UUU, el launcher te pide el archivo UniversalUE4Unlocker.dll. El launcher no lo incluye ni lo descarga automáticamente.

¿De dónde se descarga?

Descarga el Universal UE4 Unlocker desde su página oficial de FRAMED:

Abrir página oficial de UUU

La página indica que los binarios del UUU v3 se distribuyen únicamente desde FRAMED. Actualmente muestra Universal UE4 Unlocker v3.0.21.

Después de descargarlo

  1. Descarga el ZIP desde la página oficial de FRAMED y extráelo en una carpeta.
  2. En el perfil del launcher, activa la opción de Universal UE4 Unlocker (UUU).
  3. Pulsa Buscar y selecciona UniversalUE4Unlocker.dll dentro de la carpeta que has extraído.
  4. Guarda el perfil y continúa con el lanzamiento del juego.

No redistribuyas el DLL ni el resto de binarios del UUU dentro de este proyecto. El launcher solo guarda la ruta al archivo que tú has descargado.

Universal UE4 Unlocker (UUU)

Errores del antivirus

Si el antivirus borra, bloquea o pone en cuarentena el launcher, casi siempre es un falso positivo: el programa no está firmado digitalmente, y mueve archivos y abre otros programas, algo que los antivirus vigilan.

Hazlo solo con el archivo descargado del repositorio oficial de GitHub. Si lo conseguiste en otro sitio, no lo excluyas. Es mejor añadir una exclusión que desactivar el antivirus por completo.

Opción 1 (recomendada): añadir una exclusión en Windows

  1. Abre Inicio y busca Seguridad de Windows.
  2. Entra en Protección antivirus y contra amenazas → Administrar la configuración.
  3. Baja hasta Exclusiones y pulsa Agregar o quitar exclusiones.
  4. Pulsa Agregar una exclusión → Carpeta y elige la carpeta donde está UE4ModLauncher.exe.
  5. Repite el paso 4 con %LOCALAPPDATA%\UE4ModLauncher.

Si ya lo borró o lo puso en cuarentena

  1. En Protección antivirus y contra amenazas abre Historial de protección.
  2. Selecciona el aviso del launcher, pulsa Acciones y elige Permitir en el dispositivo (o Restaurar).
  3. Si el archivo ya no está, vuelve a descargarlo tras añadir la exclusión.

Si aparece «Windows protegió tu PC»

Es SmartScreen. Pulsa Más información y luego Ejecutar de todas formas.

Opción 2: desactivar la protección un rato

  1. En Protección antivirus y contra amenazas → Administrar la configuración, desactiva Protección en tiempo real.
  2. Descarga o ejecuta el launcher.
  3. Vuelve a activarla en cuanto termines. Windows la reactiva sola pasado un tiempo o al reiniciar.

Otros antivirus (Avast, AVG, Kaspersky, Norton, ESET, McAfee, Bitdefender…)

Abre el programa y busca en sus ajustes Exclusiones, Excepciones o Lista blanca. Añade la carpeta del launcher y %LOCALAPPDATA%\UE4ModLauncher. Los nombres cambian según el programa.

Antivirus errors

If your antivirus deletes, blocks or quarantines the launcher, it is almost always a false positive: the program isn't digitally signed, and it moves files and starts other programs, which antivirus software watches for.

Only do this with the file downloaded from the official GitHub repository. If you got it anywhere else, don't exclude it. Adding an exclusion is better than turning your antivirus off completely.

Option 1 (recommended): add an exclusion in Windows

  1. Open Start and search for Windows Security.
  2. Go to Virus & threat protection → Manage settings.
  3. Scroll to Exclusions and click Add or remove exclusions.
  4. Click Add an exclusion → Folder and pick the folder containing UE4ModLauncher.exe.
  5. Repeat step 4 with %LOCALAPPDATA%\UE4ModLauncher.

If it was already deleted or quarantined

  1. In Virus & threat protection open Protection history.
  2. Select the launcher's alert, click Actions and choose Allow on device (or Restore).
  3. If the file is gone, download it again after adding the exclusion.

If you see “Windows protected your PC”

That is SmartScreen. Click More info, then Run anyway.

Option 2: turn protection off for a while

  1. In Virus & threat protection → Manage settings, turn off Real-time protection.
  2. Download or run the launcher.
  3. Turn it back on as soon as you finish. Windows also re-enables it by itself after a while or on restart.

Other antivirus programs (Avast, AVG, Kaspersky, Norton, ESET, McAfee, Bitdefender…)

Open the program and look in its settings for Exclusions, Exceptions or Whitelist. Add the launcher's folder and %LOCALAPPDATA%\UE4ModLauncher. Names vary by program.
